# 日→英 テスト — EIGO NO PARTNER

日本語の文を見て英語で答える、日→英専用の練習クイズです。
`translation-test-app` からクラウドインフラ（Vercel / Neon / next-auth / Resend / AI採点）を
すべて除去し、`english-word-typing-app` と同様の **単一HTMLファイル構成** に作り直したものです。

- サーバー不要・DB不要・認証不要・インターネット接続不要（フォント読み込みを除く）
- `english_test.html` をブラウザで開くだけで動作
- 英→日モード・AI採点（Gemini/OpenRouter）・ログインは非搭載

---

## 動作環境（WSL 前提）

本プロジェクトは **WSL（Windows Subsystem for Linux）上に配置して運用** します。

- 以前は Windows のローカルフォルダ（`english-test-win`）で作業していましたが、
  パス・文字コード・Python/uv まわりのエラーが多発したため、WSL 上へ移設しました
- 現在のプロジェクト名および配置先は `english-test-wsl`
- Windows 側フォルダ（`/mnt/c/...`）ではなく、WSL 側のホーム配下
  （例: `~/projects/english-test-wsl`）に置くことで、`build.py` の実行や
  ブラウザからのファイル参照が安定します
- リポジトリは GitHub からクローンして取得します

```bash
git clone https://github.com/stangler/english-test-wsl.git
cd english-test-wsl
```

## 使い方

1. `english_test.html` をダブルクリックしてブラウザで開く
2. レッスン・パートを選んで「開始」（必要に応じて「シャッフルする」を有効化）
3. 日本語の問題文を見て英語で入力 → Enter または「判定」
4. テスト後は「間違いのみ再挑戦 / 全部再挑戦」で復習、「履歴を見る」で過去の結果を確認
5. 「📉 苦手分析」で、どの問題をどれだけ間違えているか・どんな傾向で間違えているかを確認
6. 「📋 問題・正解一覧」で、各レッスンの問題と正解をまとめて確認（詳しくは「問題・正解一覧」を参照）

正誤判定はローカルのJSのみで行われます（句読点の無視・縮約形展開・冠詞除去・NFKC正規化などをした上で比較。詳しくは「正誤判定のルール」を参照）。

問題文の下や一覧画面の 🔊 ボタンで、正解の英文を読み上げて聞けます（詳しくは「音声読み上げ」を参照）。

## 正誤判定のルール

入力した英文と正解を、次のように正規化してから比較します（大文字・小文字は区別しません）。

- **句読点は無視**: `. , ! ? ; : "` の有無は判定に影響しません（例: `Also I practice it ...` と `Also, I practice it ...` はどちらも正解）
- **縮約形は展開して比較**: `I'm` = `I am`、`don't` = `do not`、`I'd` = `I would`、`What's` = `What is` など。`can't` と `cannot`、`can not` も同じ扱いです
- **アポストロフィの種類**: 曲がったアポストロフィ（`’`）で入力しても、通常の `'` と同じに扱います
- **ハイフンは空白扱い**: `hip-hop` と `hip hop` はどちらも正解です
- **冠詞（a / an / the）は無視**
- **全角・半角の違いは吸収**（NFKC正規化）
- **語順違い・単語の違いは不正解**です。ただし自然な語順違いのうち、次の別解はあらかじめ登録しています

| 正解データ | 別解として認める文 |
| --- | --- |
| Also, I practice it in my house every day. | Also, I practice it every day in my house. |
| Last weekend, I went to Lake Kaede. | I went to Lake Kaede last weekend. |
| Today, I went to the summer festival with Mika and Lisa. | I went to the summer festival with Mika and Lisa today. |
| I go to his house for the lessons on Sundays. | I go to his house on Sundays for the lessons. |
| In this class, 8 students want to go to Hokkaido. | 8 students in this class want to go to Hokkaido. |

- **日本語が同じで英語が複数ある問題**（例:「いいえ、できません。」→ `No, I can't.` / `No, I cannot.` / `No, he cannot.`）は、データ内のどの英語を答えても正解になります

別解を増やすときは、`english_test.html` 内の `ALT_ANSWERS`（キーは正解データの英文、値は別解の配列）に追記します。

## 音声読み上げ

英文を耳でも確認できるよう、🔊 ボタンで正解の英文を読み上げます。

- **出題画面**: 日本語の問題文の下の 🔊 ボタンで、その問題の正解の英文を読み上げます
- **結果画面**: 「✏️ 間違えた問題」の各項目で、「正解: …」の行の右端にある 🔊 ボタンから読み上げます。間違えた問題を、答え合わせしながら聞き直せます
- **一覧画面**: 「問題・正解一覧」の各正解の右にある 🔊 ボタンから読み上げます。検索やパートで絞り込んだ後も、表示中の問題の英文を読み上げます。「答えを隠す」がONの間は、🔊 も英語側と一緒に隠れます
- 別の 🔊 を押すと前の読み上げは止まります。次の問題へ進んだとき、結果画面や一覧画面から別の画面へ移ったとき、一覧でレッスン・パート・検索を切り替えたときも止まります
- ブラウザ内蔵の音声合成（Web Speech API）を使うため、音声ファイルの用意やインターネット接続は不要です。声の種類や聞こえ方は、ブラウザ・OS によって異なります
- 音声合成に対応していないブラウザでは、🔊 ボタンは表示されません
- 日→英のテストのため、出題中に 🔊 を押すと正解の英文が聞こえます。答えを考えるときに使うか、答え合わせの後に使うかは、お好みで使い分けてください
- 英文中の「...」は読み上げません

## 問題・正解一覧

開始画面の「📋 問題・正解一覧」から、各レッスンの問題（日本語）と正解（英語）を一覧で確認できます。
復習や、テストの前に出題範囲を見渡したいときに使えます。

- **レッスン切替**: Starter と Lesson 1〜5 をボタンで切り替えます。開始画面でレッスンを選んでから開くと、そのレッスンの一覧が開きます
- **パートで絞り込み**: レッスン内のパートごとに見出しを付けて表示します。「すべて」または特定のパートだけに絞れます
- **別解の併記**: 判定で正解になる別解（「正誤判定のルール」の語順違い・日本語が同じ問題の別の英語）を「別解:」として併記します
- **検索**: 日本語・英語のどちらでも検索でき、一致した部分がハイライトされます（選択中のレッスン内が対象）
- **答えを隠す**: チェックを入れると英語側が隠れ、タップした問題だけ表示できます。日本語を見て自分で答えを思い出す練習に使えます
- **音声読み上げ**: 各正解の右の 🔊 で読み上げます（「音声読み上げ」を参照）
- 印刷時は、ボタンや検索欄を除いた問題と正解だけが出力されます

別解は `english_test.html` 内の `ALT_ANSWERS` などの判定用データをそのまま使うため、
別解を追加すると一覧にも反映されます。

## 履歴と進捗の確認

テスト履歴と出題済みの進捗はブラウザの `localStorage` に保存されます。

- 「📊 履歴を見る」で全履歴を一覧表示
- 「パート別統計」をクリックすると、選択したレッスン/パートの履歴のみに絞り込み
- 「すべて表示」または「✕ クリア」でフィルタを解除
- 上部の「表示回数 / 平均正答率 / 最高記録」はフィルタ後の値を反映
- 開始画面の進捗パネルで、レッスン/パートごとの着手状況（着手済み / 未着手）を確認

保存に使う `localStorage` のキーは次のとおりです。

| キー | 内容 |
| --- | --- |
| `ja2en_quiz_history` | テスト終了時の結果（レッスン / パート / 正解数 / 総数 / 正答率） |
| `ja2en_quiz_attempted` | 出題済みの進捗 |
| `ja2en_quiz_wordstats` | 問題単位の記録（出題回数・間違い回数・誤答・誤答タイプ） |

「🗑 履歴をすべて削除」を実行すると、上記3つがすべて削除されます。

## 苦手分析

「📉 苦手分析」（開始画面・結果画面・履歴画面から開けます）で、問題ごとの間違いと傾向を確認できます。
問題単位の記録は **1問答えるたびに保存** されるため、テストを途中でやめた分も残ります。

- **間違い回数ランキング（上位30問）**: 間違い回数 / 出題回数、直近の誤答、誤答タイプ
- **レッスン/パート別の誤答率**
- **誤答タイプ別の件数**
  - 空欄（未回答） / 句読点・記号のミス / 語順違い / 語形違い（-s・-ed・-ing など） / 綴りミス / 語の欠落 / 余分な語 / 別の単語
  - 句読点の違いは正解扱いになったため、「句読点・記号のミス」には新しい記録は増えません（過去の記録にのみ残ります）
- **英文の特徴別の誤答率**
  - 疑問文 / 疑問詞で始まる文 / 否定文 / 助動詞を含む / 過去形を含む / 進行形 / 縮約形を含む / 文の長さ（1〜3語・4〜6語・7語以上）
- 全体の誤答率より10ポイント以上高い項目には ▲ が付き、回答3回未満の項目は「データ不足」と表示されます
- 「⬇ JSONエクスポート」で、問題別の記録と履歴をまとめてダウンロードできます

注意点:

- 問題単位の記録は、この機能を追加した後に解いた分から貯まります（それ以前のテスト分は復元できません）
- 誤答タイプと英文の特徴は自動判定のため、あくまで目安です

## ファイル構成

```
├── json/
│   └── words-data.js     # window.WORDS = [...] 形式の単語データ（build.pyで生成）

├── build.py               # csv → json/words-data.js 変換スクリプト

├── uv.lock                # uv のロックファイル
└── README.md
```

## 単語データの再生成

csv を差し替えた場合は再生成してください。

```bash
cd ~/projects/english-test-wsl   # WSL 側のプロジェクトへ移動
uv run python build.py
```

`csv/` 内のCSVファイル（Lesson / Part / 英語 / 日本語の列構成）を読み込み、
`json/words-data.js` を上書き生成します。別解展開（人称代名詞・可能形動詞など）も
`translation-test-app` の `build.py` と同じロジックを流用しています。

## translation-test-app との違い

| 項目 | translation-test-app | 本アプリ |
| --- | --- | --- |
| クイズモード | 英→日・日→英 | 日→英のみ |
| フレームワーク | Next.js 14 | なし（静的HTML） |
| DB | PostgreSQL + Prisma | なし（localStorage） |
| 認証 | next-auth + Resend | なし |
| 採点 | 日→英はローカル比較、英→日はAI(Gemini/OpenRouter) | ローカル比較のみ |
| デプロイ | Vercel前提 | ローカルで `english_test.html` を開くだけ（WSL 上に配置） |
| 履歴保存 | あり(DB) | あり（ブラウザの localStorage） |
| 苦手分析 | なし | あり（問題別の誤答・誤答タイプ・英文の特徴別） |
| 音声読み上げ | なし | あり（ブラウザの音声合成。出題画面・結果画面・一覧画面の 🔊） |
| 問題・正解一覧 | なし | あり（レッスン/パート別、検索、答えを隠す、別解の併記） |
